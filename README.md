# 🧳 旅行规划 Travel Planner

本地运行的一站式旅行规划工具：AI 生成行程、小红书攻略一键导入、按天日程看板（拖拽编排）、高德地图路线（分段交通方式）、开销记账与多人分摊、行前清单、导出打印。数据全部保存在本机，AI 服务与地图 Key 由你自己配置。

> 面向个人与亲友使用的本地工具，无账号体系、无云端依赖，`npm run dev` 即用。

## ✨ 功能特性

### 🤖 AI 能力（自带 Key，服务可自选）
- **AI 规划行程**：输入目的地/日期/人数/预算档/偏好，流式生成 → 结构化校验（失败自动重试）→ 自动匹配地图坐标 → 预览确认 → 一键导入
- **小红书攻略导入**：粘贴攻略正文，AI 提取店名景点、按动线分天、过滤广告内容，整理成可编辑行程
- **AI 调整行程**：自然语言描述调整要求，生成与现有行程的**逐项对比**（新增/修改/删除，字段级变化展示），勾选后仅应用选中的变更，开销关联不受影响
- 兼容 **OpenAI 协议**（DeepSeek / Kimi / 通义 / one-api 网关等通用）与 **Anthropic 协议**，应用内配置服务地址、API Key、模型名

### 📅 日程编排
- 多行程管理；按天分栏看板，行程项分六类（景点/交通/住宿/餐饮/购物/其他）
- 拖拽排序、跨天移动；时间段、预估费用、备注
- 配置和风天气后，看板显示行程期间逐日天气

### 🗺️ 地图路线（高德）
- 搜索选点定位、按天彩色标注与动线、点击列表定位
- **每两点之间可独立选择交通方式**（直线/驾车/步行/骑行），逐段显示距离、耗时、过路费、打车费估算，按天汇总
- 定位纠错：编辑弹窗内搜索重新定位，或**在地图上直接点选新位置**（自动反查地址）

### 💰 开销管理
- 记账（分类/关联行程项）、预算对比、分类与每日统计图表
- **多人分摊**：记录垫付人与分摊人，自动计算各人净额与最少转账结算方案

### 🧰 实用工具
- 行前清单（常用物品一键添加）
- 导出 Markdown / JSON 备份（可再导入恢复）/ 打印页面（另存 PDF）
- **多用户**：管理员创建账号（不开放注册），数据按用户隔离，行程可共享给其他用户（只读/可编辑），内置用户与行程管理页
- **两步验证（可选）**：每个用户可在「安全设置」中开启 TOTP 两步验证（Google/Microsoft Authenticator 等扫码绑定），管理员可为丢失验证器的用户解除
- **服务器部署**：Docker Compose 一键部署，见 [DEPLOY.md](DEPLOY.md)

## 🛠️ 技术栈

| 层面 | 选型 |
|---|---|
| 框架 | Next.js 15（App Router）+ React 19 + TypeScript |
| UI | Ant Design 5 · dnd-kit（拖拽）· ECharts（图表） |

## 🚀 快速开始

环境要求：Node.js 20+

```bash
cp .env.example .env   # 本地保持默认即可；部署时需修改 AUTH_SECRET
npm install            # 安装依赖（自动生成 Prisma 客户端）
npm run db:push        # 初始化 SQLite 数据库（首次运行）
npm run dev            # 启动，访问 http://localhost:3000
```

首次访问会引导创建管理员账号，之后用管理员进入「设置」页配置：

| 配置 | 说明 | 申请入口 |
|---|---|---|
| AI 服务 | 服务地址 + API Key + 模型名，带连通性测试 | 你所使用的 AI 服务商 |
| 高德地图 | 「Web端(JS API)」Key（含安全密钥）+「Web服务」Key，个人开发者免费 | [高德开放平台](https://console.amap.com/dev/key/app) |
| 和风天气（选填） | 专属 API Host + Key，配置后显示行程天气 | [和风天气控制台](https://console.qweather.com) |

所有 Key 仅保存在本机 `data/app.db`（已被 .gitignore 排除），第三方请求一律由本地服务端代理转发，不经过任何中间服务。

## 📦 数据与备份

- 全部数据在本机 `data/app.db` 单文件中，备份 = 复制该文件
- 行程可导出 JSON 备份并随时导入恢复（含日程、开销、清单及其关联）

## 🚢 部署到服务器

支持 Docker Compose（推荐）与 PM2 两种方式，含访问密码认证与 nginx HTTPS 配置示例，详见 [DEPLOY.md](DEPLOY.md)。

## 🔧 开发

```bash
npm run build                                        # 生产构建（含类型检查）
node scripts/smoke-all.mjs                           # 接口冒烟测试（需先启动服务，BASE_URL 可覆盖）
npx prisma db push                                   # 变更 schema 后同步数据库（需重启 dev 服务器）
```
